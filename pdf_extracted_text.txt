Проект «ДомПрогноз» — Система прогнозирования цен на
жильё
1. Введение
В условиях нестабильного рынка недвижимости и высоких ипотечных ставок
покупатели, продавцы, риелторы и инвесторы испытывают острую
потребность в объективной оценке стоимости жилья. Существующие
платформы (ЦИАН, Авито, Яндекс.Недвижимость) предоставляют лишь
сырые объявления без аналитики и прогнозирования.
Проект «ДомПрогноз» — это интерактивное веб-приложение, которое
агрегирует данные о рынке недвижимости, визуализирует динамику цен и
предоставляет ML-прогноз стоимости жилья на основе характеристик
объекта и макроэкономических факторов.

--- PAGE 2 ---
2. Цели и задачи проекта
Цель
Разработать MVP продукта для прогнозирования и анализа цен на жильё,
доступного конечным пользователям через браузер.
Задачи
1. Собрать и обработать данные о рынке недвижимости по городам юга
России
2. Провести исследовательский анализ данных (EDA)
3. Построить ML-модель прогнозирования стоимости жилья
4. Визуализировать аналитику в интерактивном веб-интерфейсе
5. Реализовать калькулятор стоимости с ипотечным расчётом и
инвестиционным анализом

4. Исследовательский анализ данных (EDA)
В ходе анализа данных были исследованы следующие аспекты:
4.1 Динамика цен
Проведён анализ динамики цен на вторичном рынке и рынке новостроек в
период с 2018 по 2025 год. Выявлен устойчивый рост цен: вторичный рынок
Ростова-на-Дону вырос с ~50 тыс. руб./м² в 2018 году до ~122 тыс. руб./м² в
2025 году (+144%).
4.2 Сравнение городов
Проведён сравнительный анализ рынков недвижимости по городам:
Город Средняя цена Рост за год
Сочи 210 тыс. р./м² +8,5%
Краснодар 118 тыс. р./м² +11,2%
Ростов-на-Дону 122 тыс. р./м² +13,5%
Ставрополь 82 тыс. р./м² +12,1%
Волгоград 78 тыс. р./м² +9,8%
4.3 Анализ по районам
Выявлена значительная дифференциация цен в зависимости от района
города. Центральный (Элитный) район Ростова-на-Дону демонстрирует
наиболее высокую стоимость — 165 тыс. руб./м².
4.4 Ключевые факторы влияния на цену
В результате анализа выявлены основные факторы, влияющие на стоимость
жилья:
+15% — рост спроса (миграционный прирост, рост населения)
•
+12% — новое строительство (объём ввода жилья в м²/год)
•
+8,5% — инфляция (влияние ключевой ставки ЦБ РФ)
•
−26% — ипотечная ставка (рыночная ставка 2025 года)

5. Модель прогнозирования
5.1 Методология
В проекте применяется комбинация трёх подходов:
1. ML-прогнозирование (scikit-learn) — для оценки стоимости
конкретного объекта
2. Линейная регрессия (statsmodels) — для выявления зависимостей
между факторами
3. Временные ряды — для прогнозирования динамики рынка
5.2 Прогноз цен до 2028 года
Модель генерирует три сценария развития рынка:
Сценарий Прогноз к 2028 Изменение Условия
Экономический спад, рост
Пессимистичный 133 000 р./м² +9% безработицы
Умеренный рост, стабильная
Базовый 152 000 р./м² +25% экономика
Снижение ставок, рост
Оптимистичный 172 000 р./м² +41% спроса
5.3 Калькулятор стоимости объекта
На основе введённых пользователем параметров модель рассчитывает:
Рыночную стоимость объекта — на текущий момент
1.
Прогноз стоимости — через 1 год и через 3 года
2.
Ипотечный расчёт — первоначальный взнос, сумма кредита,
3.
ежемесячный платёж
Инвестиционный потенциал — доходность от аренды,
4.
потенциальный доход за 3 года

6. Описание продукта
6.1 Функциональные модули
Модуль «Обзор рынка»
Предоставляет общую аналитику рынка недвижимости выбранного города:
ключевые показатели, динамику цен, распределение стоимости по районам.
Модуль «Объявления»
Агрегированная база актуальных объявлений о продаже недвижимости с AI-
оценкой каждого объекта. Пользователь может сразу видеть, завышена или
занижена цена конкретного объявления относительно рыночной.
Модуль «Прогноз цен»
Визуализация ML-прогноза динамики цен с тремя сценариями.
Отображаются ключевые факторы, влияющие на прогноз модели.
Модуль «Калькулятор»
Интерактивный инструмент для оценки стоимости конкретного объекта.
Пользователь задаёт параметры через слайдеры и мгновенно получает оценку
стоимости, ипотечный расчёт и анализ инвестиционного потенциала.
6.2 Технический стек
Уровень Технологии
Сбор данных Python, Scrapy, Playwright
Хранение PostgreSQL, Redis
ML и аналитика scikit-learn, statsmodels
Backend FastAPI, REST API
Frontend React, Recharts, Vite

9. Заключение
Проект «ДомПрогноз» представляет собой завершённый MVP аналитической
платформы для рынка недвижимости. Продукт решает реальную проблему
информационной асимметрии на рынке жилья, предоставляя всем
участникам сделки объективные данные, прозрачную аналитику и ML-
прогнозирование. Платформа охватывает города юга России и имеет
потенциал для масштабирования на другие регионы.
